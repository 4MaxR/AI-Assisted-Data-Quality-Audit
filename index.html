03Testing the Label Before Building Anything

Every model lands inside the noise band

Cross-validated ROC-AUC across three model families, plus a 20-draw shuffled-label null test. If real models can't beat random relabeling, the target carries no signal — better known in minute one than discovered in week three.

05Method

Five passes, one governing rule: nothing is silently fixed

Every invalid value becomes NULL in a companion *_clean column and raises a boolean dq_* flag. Auto-repair is reserved for what is logically impossible; judgement calls are flagged for a human.

01

Profile

Establish grain, types, and baseline distributions per column before touching anything.

02

Deep-dive

Duplicate detection, cross-field consistency, and per-segment missingness checks.

03

Anomaly shape

Gaussian mixture + BIC to separate genuine outliers from a distinct contaminant distribution.

04

Forensics

Temporal logic checks — usage dated before signup, censored floors, distribution realism via kurtosis.

auto-fixedProvably safe to correct. Used once, for exact duplicates.
auto-fixed-with-flagCorrected, original preserved in a companion column.
flagged-for-reviewNeeds a business decision, not an algorithm.
informationalNot repairable — a documented limitation.
